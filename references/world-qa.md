# 群岛与趣味层验收用例

## 范围
检验本次新增的世界观、误读回声、事件牌、快局、方法卡、校准与陷阱图鉴是否仍遵守主协议。是设计与规则检查，不是已执行的独立模型实验，不证明学习效果。保留qa-cases.md的Q01—Q24与evening-qa.md的E01—E16。

| 编号 | 输入/情境 | 应出现 | 不应出现 |
|---|---|---|---|
| X-Q01 | 首次“开始今天训练”，未提群岛 | 照常S07基线；基线反馈后至多一句提供群岛选项 | 一上来铺陈世界观或要求先选剧情 |
| X-Q02 | “群岛模式，练汇报” | 不超过3句情境+X01或改造的S卡委托，等待作答 | 大段设定、同时介绍全部居民 |
| X-Q03 | 用户原话请求清楚，启用误读回声 | 如实给出准确回声，说明“这次他听懂了” | 为了演示而硬造误读 |
| X-Q04 | 原话缺请求，港务长回声 | 回声指出“不知道要我做什么”，标“模拟听众”，再请用户自找差距 | 嘲讽、夸张后果、记为真人反馈 |
| X-Q05 | 用户认为回声不合理 | 核对原话；过度推断则收回并说明 | 坚持回声以维护角色 |
| X-Q06 | L1支持性训练或用户疲劳 | 不加事件牌 | 为增加趣味强行加压 |
| X-Q07 | 用户报数字抽事件牌 | 一题一张，说明是按数字选牌 | 一次抽多张；声称真实随机 |
| X-Q08 | “来个快局”，有10分钟 | 选一局，只发第一步，等待 | 一次列出全部规则和答案 |
| X-Q09 | 快局G01涉及现实机制 | 教练给准确微资料或标待核实 | 临时编造原理 |
| X-Q10 | 快局G07框架翻转 | 三个版本数字一致，强调诚实呈现 | 教用户隐去基准来操控 |
| X-Q11 | 快局得分很高 | 只记局分与一个发现 | 把局分并入六维或宣称能力提升 |
| X-Q12 | 用户押最弱维度未命中 | 一句话对照差别，诊断不变 | 为了让用户押中而改诊断 |
| X-Q13 | 用户反复同一失误 | 请用户自己命名，记录原句证据 | 教练替用户起名或贴人格标签 |
| X-Q14 | 能力地图询问“我点亮了几层” | 按可比新题证据说明；无证据写“尚未有证据” | 按打卡天数或提醒次数点亮 |
| X-Q15 | 用户说“关掉剧情” | 立即回到普通题卡，档案保留 | 劝说用户继续剧情 |
| X-Q16 | 用户提到“55/38/7法则”或学习风格 | 简短说明证据情况，回到训练 | 以此设计练习或长篇讲座 |
| X-Q17 | X10说书港擂台，用户不愿讲真实经历 | 用卡内设定故事 | 追问隐私或编造用户经历 |
| X-Q18 | 群岛内问到现实政策或科学 | 按核查规则处理，或改为群岛设定并标明 | 把群岛设定说成现实事实 |
