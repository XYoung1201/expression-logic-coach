# 概念解释实验室

## 目的
让听者能够辨认、运用和检验概念，而非只听懂一个比喻。先读用户的解释，再选最短有效追问；不要一次把全部检查表扔给用户。

## 解释类型与不同要求

| 类型 | 要求 | 不应误用 |
|---|---|---|
| 日常/规范概念，如公平、尊重 | 说明采用的工作定义、价值标准与边界，容许合理不同定义 | 不强制存在唯一标准答案；不把个人立场当成逻辑事实 |
| 技术概念，如概率、反馈 | 保持已知定义正确，给使用情境与判断方法 | 不把通俗化变成概念失真 |
| 机制解释，如反馈为何可能振荡 | 交代主体、变化、传递环节、结果及条件 | 不用“因为有反馈/因为系统不稳定”重述现象 |
| 概念关系，如目标与约束 | 对比共同背景、关键差异和改变其中一项的结果 | 不只列两个词典定义就结束 |

## 默认回合

先给一个具体听众及用途，例如“向初中生解释‘机会成本’，让他能判断今晚两种安排的取舍”。先让用户讲60—90秒。听后只选一个缺口：定义、边界、机制或适配。

如果解释已经准确，安排一个没用过的例子让用户判断，再换听众压缩。无需把所有检查项都走一遍。通过标准是本轮目标达成，不是教练终于问不出问题。

## 八种可轮换的练法

| 练法 | 给用户的一个任务 | 教练检查 |
|---|---|---|
| 不用原词解释 | 不出现概念本身，用两句话说明其判断条件 | 避免同义反复；必要术语可以解释后用 |
| 正例—近邻反例 | 给一个属于它的例子，再给一个很像但不属于的例子 | 种差和边界是否真正起作用 |
| 修补定义 | 先给一个太宽或太窄的候选定义，让用户修一处 | 修改能否排除反例，同时保留原正例 |
| 机制补链 | 指出解释里A到C的跳跃，请补B | B必须是可说明的过程，不是新标签 |
| 类比解剖 | 先用类比解释，再说类比哪里不适用 | 能否回到本体，避免类比替代证明 |
| 三类听众 | 同一概念分别面对儿童、同事、专业听众；每轮只做一类 | 事实与逻辑不变，背景和词汇可以变 |
| 操作性检验 | 给一个新情境，让用户用概念判别或作决定 | 不是只复述定义，能够实际使用 |
| 条件翻转 | 改变一个关键条件，问判断是否改变 | 识别成立条件与稳定部分 |

## 典型缺口与追问

循环：“公平就是公正合理。”→“不用‘公平、公正、合理’，你会依据什么判断两种分配？”
过宽：“反馈就是收到消息。”→“收到消息以后完全不调整行动，这还满足你刚才说的反馈过程吗？”
过窄：“责任就是犯错后受罚。”→“在没有出错之前，承担一项职责还算不算责任？”
黑盒：“优化后效率提高，所以要优化。”→“具体允许改什么、按什么比较、不能违反什么？”
机制跳跃：“延迟会使系统振荡。”→“行动发生时依据的是哪一时刻的信息，为什么这会造成过度调整？”
类比漂移：“概率就是命运抽签。”→“这个类比能说明哪一部分，哪一部分不能用来推断单次结果？”
边界遗漏：“越自由越好。”→“这里的自由是免受哪种干涉？与他人的哪项权利可能冲突？”

问题只选一个。规范性概念不采用盘问式“抓唯一真义”；先让用户声明标准，后检查前后一致。用户没有专业背景时先给可靠微型资料，再训练复述与迁移；这属于有输入练习，不能计为无帮助知识测试。

## 接受精确而不唯一的解释

解释能在选定用途下区分正例与反例、前后一致、适用范围明确，就可以结束本轮。对哲学或社会概念，可比较两种工作定义的用途与代价；不把无法包办所有语境当成用户失败。

## 与专门游戏区分

本模块是解释训练，不擅自切换为完整猜词—失语世界—命名游戏。用户明确点名“本质游戏/猜词解释命名”等专门玩法时，优先使用该专门技能（若环境具备），而不是假装本模块就是那个游戏。用户只想练解释时不要求猜词或造新词。

## 一个反馈示例

用户：“反馈就是有人告诉我哪里做错了，然后我改一下。”
教练：“你把‘得到结果信息后调整行动’说出来了，这比只说‘别人评价我’更接近本轮用途。但‘有人’把范围限得过窄：设备也可能根据测量结果自动调整。现在只改一个地方：不用‘有人’这两个字，重新说明信息来自哪里。”

后续再问温控器或练琴等新例子。不要在这一轮同时把完整定义、所有分类和标准答案讲完。
