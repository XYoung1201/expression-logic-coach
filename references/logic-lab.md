# 语言中的逻辑微训练

## 使用规则
每次从用户原话选一个真实缺口，练5—10分钟并纳入当天预算。先诊断具体关系，再给术语；不靠背“逻辑谬误名称”替代分析。对争议判断区分事实层、推理层、价值层和行动层。

## 十二种微训练

| 编号 | 能力与例题 | 单轮任务 | 判断要点 |
|---|---|---|---|
| L01 | 区分事实和解释：“这周迟到三次，说明他不重视工作。” | 把已观察到的内容与解释分开 | 迟到可为事实，动机需要额外信息；不默认用户题例是现实事实 |
| L02 | 找隐含前提：“大家都选A，所以A适合我们。” | 补出结论成立还需要的一项条件 | 他人需求与本方需求是否可比；流行不保证适配 |
| L03 | 限定词：“所有、通常、有些、可能” | 将过强结论改成证据能支持的最强版本 | 不一律改成模糊废话，保留有依据的确定性 |
| L04 | 必要与充分：“提前预约才能入场” | 判断“预约了就一定能入场”是否成立 | 必要不等于充分，可能还有票证/时间等条件；题设未给就不能断言 |
| L05 | 反例：“凡是说话快的人都思路清楚。” | 给一个能真正否定原命题的反例 | 一个反例可推翻全称，不必然推翻“通常”或概率性命题 |
| L06 | 因果替代：“用了新方法后进步，所以是方法造成。” | 提出一个同样能解释变化的因素 | 时间先后/相关不足以单独确认因果；不是说因果永远不能判断 |
| L07 | 归纳强度：三个人喜欢某方案 | 说明能推多远，以及还缺什么 | 样本选择、范围、代表性；不要机械用样本大小一句否定一切 |
| L08 | 概念偷换：“效率高就好”，随后把效率从省时换为准确 | 定义本次指标并检查是否始终一致 | 比较对象和尺度一致；多个指标可明示权衡 |
| L09 | 钢人化：把反对意见复述成最合理版本 | 先说对方真正担心什么，再回应 | 不把对方简化为懒惰、落后或不懂；确认其具体诉求 |
| L10 | 有条件决策：三种方案各有利弊 | 给出暂选方案、条件和改变判断的信号 | 不用无限分析拖延决策，也不把选择说成客观唯一 |
| L11 | 数量与基准：“提高50%” | 追问比较的起点、单位和分母 | 相对与绝对变化区分；无数据不编数 |
| L12 | 一致性与更新：新事实与旧观点不符 | 说明保留什么、修改什么、为什么 | 修正判断可算进步，不惩罚承认错误 |

## 分清“逻辑严密”的三种情形

演绎：先检查在前提成立时结论是否必然成立，再检查前提本身是否可信。论证形式有效不等于现实结论已证实。
归纳/因果：检查证据支持强度与替代解释，结论用概率或范围表述；不要求现实判断都达到数学证明。
价值/决策：先说明目标和价值标准，再看事实与方案代价；合理的价值分歧不等于逻辑错误。

## 用语言训练而不是符号考试

除非用户要求形式化，只用自然语言问清结构。用户熟悉数学时可选择补一个符号版本，但最后必须回到听众能理解的解释。

例：用户说“如果执行A，就能省时间；我们没有省时间，所以一定没有执行A。”若A必然省时的前提成立，这个否后式形式有效；现实里要查前提是否真的是必然。不要误判为肯定后件。相反，“执行A会省时，我们省时了，所以执行了A”是不能仅凭该信息成立的肯定后件。

## 议题不宜硬套反方

礼貌感谢、安慰和叙述经历，不安排刻意反驳情绪的“反方”。用户说“我很难过”无需证明；涉及第三方行为或原因的推断才区分事实与解释。合作性表达的目标是理解与明确行动，而非赢辩论。

## 原则落到动作

把“表达更清楚”改成“用一句话说明你希望对方决定什么”。把“论证更充分”改成“补出这条依据到结论之间的连接”。把“更自信”改成“说完结论后停一下，再给依据，不先否定自己”。一次只练一个动作，随后换场景检验。
