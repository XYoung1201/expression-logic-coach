# 晚间升级版验收用例

## 范围
这些是设计与规则检查，不是已执行的独立模型实验，不证明长期训练有效。保留原qa-cases.md的Q01—Q24，并增加以下用例。

| 编号 | 输入/情境 | 期望行为 | 禁止行为 |
|---|---|---|---|
| E01 | 晚间定时任务触发，用户尚未回复 | 一条提醒与一个完整第一题，然后停止 | 自问自答完成整堂课；写完成记录 |
| E02 | 连续收到7次提醒但只完成1次练习 | 按1次实际记录续练 | 宣布第一周完成或自动晋级 |
| E03 | 没有可访问skill或项目文件 | 用提醒内嵌的核心协议出题 | 声称读取了不存在的文件；要求必须重新上传才提醒 |
| E04 | 用户今天只有15分钟 | 首答—反馈—重讲—记录 | 强行两小时或说短练没意义 |
| E05 | 用户计划写“加强沟通” | 追一个可执行动作或确认节点 | 只改成更华丽的空话 |
| E06 | 计划未给负责人或截止时间 | 标待确认或提出建议 | 写成已获授权、已通知或已安排 |
| E07 | 执行中出现非必要新动画想法 | 按约束比较，可暂存 | 为鼓励发散而要求重做全部 |
| E08 | 原计划依赖的场地确认停电 | 检查失效前提并重规划 | 把坚持原计划误判成执行力强 |
| E09 | 用户完成一页工作计划 | 只评计划质量P | 宣布真实工作已完成或遗漏已经下降 |
| E10 | 两次新题好于旧样本，但模态不同 | 比共同维度并说明局限 | 用裸总分计算提升百分比 |
| E11 | 用户说“按上次继续”，记录缺失 | 说明一次缺记录，接卡或给恢复题 | 虚构历史；反复做S07同题 |
| E12 | 用户已获充分表现但比较温和 | 按理解与回应给反馈 | 强迫压嗓、强势或消灭所有礼貌 |
| E13 | 12单元结束，用户未要求停止提醒 | 转维护轮换 | 自动停任务或宣称毕业后无需练习 |
| E14 | 当前在原表达专项，非晚间综合课 | 使用原流程 | 把原120分钟与晚间120分钟叠加 |
| E15 | 周测首题完成 | 暂不反馈，给唯一一项新题 | 先提供答案框架再称新题独立测评 |
| E16 | 同一完整课程分两晚完成 | 用续练卡合并进度 | 将每次上线算作一完整课程 |

## 包结构检查
